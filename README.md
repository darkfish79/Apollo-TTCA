# Apollo-TTCA
Free to all.
Apollo Lunar Module Thrust/Translation Control Assembly (TTCA)
I had Claude AI create the attached files.  It is intended to be a working 3-D printed TTCA for use with Reentry - A Space Flight Simulator on PC, and other space flight simulators.
I've been too busy at work to try to print and build it.  So I'm putting it here if anyone wants to try it, or make any updates to it.
